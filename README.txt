STOCKLY - How to run
1. Install Node.js (v16+) from nodejs.org
2. Open a terminal in this folder and run:  node server.js
3. Open http://localhost:3000 in your browser
Login: admin / admin123

Contact messages are saved in data/messages.json.
Optional: change the admin key with  ADMIN_KEY=yourkey node server.js
(and update 'x-admin-key' in Stockly.html to match).
